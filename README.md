
# MyJailbreak

An independent iOS security research and jailbreak development project.

## Target device

- Device: iPhone 11
- Chip: Apple A13 Bionic
- Test firmware: iOS 18.6

## Development goals

- Study the existing source code and its architecture.
- Make documented, testable changes.
- Build reproducibly using a remote development workflow.
- Test compatibility before claiming a successful jailbreak.
